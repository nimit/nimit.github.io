this project creates a static portfolio website. my resume is defined as a JSON file with its types in src/cvTypes.ts and content in cv.json (do not modify unless explicitly asked).

a blog is also hosted on the website with its content in markdown files (src/content)

the website is built using react, tailwindcss, framer-motion, and typescript. it aims to be a minimal, information-dense but still easy to read and visually appealing website.
